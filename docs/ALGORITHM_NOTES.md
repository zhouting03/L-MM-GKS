# 与论文和前述伪代码的对应关系

参考：M. Pasha, E. de Sturler, M. E. Kilmer, *A provably convergent MM-GKS variant for large-scale inverse problems*, arXiv:2609.17229v1, 2026，算法3.1–3.3、4.1及第5–7节。

## 公式与实现

权重为`wd=hypot(A*x-d,epsP).^(p-2)`、`wr=hypot(Psi*x,epsQ).^(q-2)`。代理是

\[
Q_k(x)=\tfrac12\|D_k(Ax-d)\|^2+\tfrac\lambda2\|P_k\Psi x\|^2+c_k,
\]

其中`D_k=diag(sqrt(wd))`、`P_k=diag(sqrt(wr))`只是数学记号；代码始终以向量行缩放应用它们。

正规算子和右端均变化：

\[
H_k=A^T D_k^2A+\lambda\Psi^TP_k^2\Psi,\quad b_k=A^TD_k^2d.
\]

求得新解后，完整梯度必须用**新wd和新wr**计算；旧代理在子空间的梯度为零，不代表平滑主目标已经驻定。`lplq_step`明确重新计算最新权重。

## 分块QR为什么与论文小问题一致

对`[D*AV,D*d]`分块QR得到紧凑R。其前k列作为数据因子、最后一列作为右端；可能含一行只贡献残差常数的分量。再叠加正则化因子：

\[
\min_z\left\|\begin{bmatrix}R_d\\\sqrt\lambda R_r\end{bmatrix}z-
\begin{bmatrix}c_d\\0\end{bmatrix}\right\|^2.
\]

正交变换保留二范数，故最小点与高维加权代理相同。代码用小矩阵SVD处理数值秩亏，不计算`Rr^(-1)`，也不形成条件数平方的高维正规方程。

## 压缩和两方向restart

正常模式先选择最多`kmin-2`个历史方向。代码直接在原空间构造解、梯度和历史方向的正交基，不依赖“梯度一定完全位于旧空间”这一额外输入假设。仅在检查新基位于旧空间后，才用坐标变换复用缓存；否则重算新列算子乘积。

`RESTART`不保留历史方向，只保留x和g。保留当前整幅图像并不等于只保留两个像素；两方向模式仍可继续更新权重并添加新方向，因此可能与回收方法达到接近的精度，但所需工作量可不同。

RBD使用真实贪心列残差分解，使用局部种子且恢复rng状态。SOC默认阈值0，避免归一化图像下直接沿用原文阈值1。SEC求一个平滑辅助小问题选择方向；其罚项作用于`Rr*z`，不是声称直接惩罚z或重新定义主目标。

本实现对全部策略统一预留两个必保留方向，因此SOC/SEC最多选`kmin-2`列；原文式(5.4)写的是最大`kmin-1`个分量。本实现采用前述推广算法的硬容量约定，并优先保留x,g，不能把这处选择称为原文代码的逐行复现。SEC实际解的是`0.5*norm(Rd*z-cd)^2 + secRho*sum(hypot(Rr*z,secEps))`，使用当前两组权重的因子；与原文未乘0.5的数据项相比，rho的数值尺度也不同。

分量式二维差分惩罚对应各向异性的平滑梯度稀疏先验；它不是把每个像素的水平、垂直差分先组合为欧氏范数的各向同性TV。

## 固定参数理论与数值保障

本包对同一目标进行MM代理投影，最新完整梯度进入后续空间。固定lambda和正平滑参数的充分下降证明适用的精确算术条件，在程序中以正交化、保留误差检查和必要时的Cauchy点比较作工程保障。Cauchy保障触发会记录次数，并重建包含当前x,g的空间。

实际浮点测试不是数学收敛证明；`nSafeguard>0`时需结合数值秩亏与尺度检查。非凸p或q小于1时，理论目标是驻点，不承诺全局或局部极小。

## 流式算法4.1的边界

每个子问题只使用当前块数据，以上一块的x和压缩空间热启动，再重算当前梯度。它不是把所有旧数据损失严格累加到同一个全局目标。流式输出接近全数据解属于实验观察，不能由每一块的下降性直接推出。内置CT示例在流式阶段丢弃当前A，结束后才重新组装小规模批量参考。

## 该包有意不做的改动

没有每步GCV，没有平滑参数递减，没有自动裁剪迭代解，也没有为了得到好看的RRE挑选真值参数。默认用double实现正交化和求解；小尺寸、矩阵自由、分块QR及有限列数是主要的资源控制手段。
