# 如何使用这些实验形成可信的对比

## 先分开三个研究问题

1. **求解器问题**：固定相同p、q、lambda、epsilon、数据和初始设置，比较FULL、RESTART及4种压缩。看相同预算的RRE、目标、完整梯度、算子次数、实际时间和缓存。不同压缩策略不必总有固定排名。
2. **存储问题**：CAPPED与LM共享kmax，CAPPED达到容量后结束，LM继续压缩迭代。它回答资源受限时是否还能改善解。两者迭代次数不同，不能用这个结果宣称相同步数下的加速。
3. **模型问题**：相同噪声样本下比较(2,1)、(1,1)、(1,0.7)。每个模型分别验证选lambda，避免直接比较不同量纲参数。跨模型的目标值不能画成同一个函数的收敛曲线。

## 推荐执行次序

```matlab
setup_lplq;
test_lplq_all();
run_lplq_experiments('compression','quick');
run_lplq_experiments('compression','paper_small');
run_lplq_experiments('memory','quick');
run_lplq_experiments('kmin','paper_small');
run_lplq_experiments('robustness','quick');
run_lplq_experiments('streaming','quick');
```

第一条实验用于检查安装和初步观察；第二条更适合展示“相近RRE、较少缓存”的取舍。不要直接追求原文500×500或PAT的大型系统。需要先了解单次耗时，再决定重复次数。

默认鲁棒性仅运行一个种子，适合调试和演示，不能据此报告统计显著性。正式论文建议同样的种子集合做至少5次重复，报告均值与标准差，同时记录每个模型的调参成本。例如：

```matlab
c = struct(); c.repetitions = 5; c.makeFigures = false;
c.saveFinalImages = false;
run_lplq_experiments('robustness','quick',c);
```

当前脚本输出逐次原始行，不自动挑选最有利种子，也不把最佳历史RRE当作最终RRE。

## 参数选择与比较的边界

独立验证观测在本合成实验中可生成，真实任务若只有一次观测则需另行设计选参。所有候选使用同一个短LM-TSVD试算规则，但有限预算的选参仍可能依赖该试算求解器；它不是精确解下的最佳lambda。严谨研究应补充网格敏感性，或用公共高精度参考求解器选参，并披露时间成本。固定lambda的实现便于把这些影响与压缩本身分开研究。

达到maxIter不等于理论收敛；达到很小相邻步长也不等于驻定。完整梯度使用最终真实算子复核，状态在CSV中单列。目标下降不要求RRE逐步下降，也不要求梯度范数单调。

## 流式CT应该怎样解释

每个块只有一组有限角度，单独问题欠定。上一块解和空间可能携带有用结构，故比较独立、仅回收解、同时回收解和空间。当前块目标仅包含当前数据，不是完整旧数据目标的精确摘要；回收并非无损保存所有历史信息。单块下降理论不能直接推出最后一块等于批量解。

示例还在全部流式阶段完成后重新构造小规模批量参考；批量参考允许看到全部数据，工作量与信息条件都不同。代码只在当前块保留稀疏CT矩阵，回收空间会对新的A重新计算乘积。

## 适合汇报的图表

- 压缩比较：统一色轴重建、绝对误差，以及RRE对求解次数和时间。
- 资源比较：缓存对迭代次数，跨尺寸`scaling.png`；缓存、工作数组估算分别标注。
- 模型比较：按噪声种类分表，报告各模型lambda及RRE；不要只展示有利于p=1的噪声。
- 流式比较：3种方案在3个块的RRE；最后再列批量参考，不暗示它们具有相同数据条件。

本包是双数据/正则权重与有限内存空间回收结合的实验实现。L_p-L_q、MM/IRLS和Krylov投影分别已有研究基础；不能仅凭代码运行就宣称该组合首次提出。更有价值的研究问题包括双动态权重下的固定参数收敛条件、空间回收的精度与资源取舍，以及鲁棒模型在异常观测下的效果，需要文献查新与充分重复实验支撑。
